# 暮灯当铺 · 这间店属于你

异世界当铺经营＋人物剧情游戏。经营方向可以选择装备修复、魔法鉴定和黑市，也能混合经营。主线目标是还清店铺贷款、拿到地契；剧情由交易、典当期限和熟客关系触发。

## 当前贷款经营篇

- 开局 560 金币周转金、3,000 金币店铺贷款，店内 6×4 格。
- 商品有不同尺寸，支持点击放置、拖放和旋转；扩建货架、建造暗格都需花钱。
- 手记仅收录继承库存和实际到柜台的货物，见过的种类持续保留；认识种类不等于鉴定了当前物品。
- 卖家、买家、典当客、服务委托与赎当回访混合到来。买家按类别、成色、预算和报价决定成交；打烊不会自动卖货。
- 学习手艺和制作招牌需要付费。招牌与收货／卖货／委托倾向影响次日客流，不保证成交。
- 抵押物在契约结清前不能出售加工；到期可赎回、宽限或依约转死当。
- 第四天起可能遇到小偷与突然搜查。观察、警铃和暗格提供不同防护。
- 每日 12 精力、18 金币开支；每七天至少累计还款 120 金币，提前还款抵扣后续最低还款。
- 还清贷款并处理完未结典当后，由玩家选择结束周目。结局体现主营业务与熟客后续。

这是首轮可玩规则与数值版本。整局模拟用于确认路线可通，不代表已经证明真实游玩时长或长期耐玩程度。

## 存档与旧版

全部进度在当前浏览器本地保存，没有外部模型或 API 依赖。

- 新版使用 `dusklight-pawnshop-v3`，版本为 3。
- 早期 v3 存档自动补建货物发现记录，保留经营进度；历史发现按现存库存、已接待客人和账本尽量恢复，不解锁尚未到柜台的货物。
- 旧七日篇的 `dusklight-pawnshop-v1` 存储键与 v1→v2 迁移原样保留。
- 检测到旧存档后，可在设置里继续旧版或导出；不会把七日进度强行换算成新版贷款进度。
- 导入文件会验证结构、资金、空间碰撞与典当引用。损坏的新存档不会自动被覆盖，可先备份原始数据。
- 不同域名的存档不共享；通过 JSON 导入导出迁移。

## 项目结构

- `lib/pawn/types.ts`：新版状态与操作类型。
- `lib/pawn/catalog.ts`：货物、付费手艺、招牌与建设配置。
- `lib/pawn/inventory.ts`：占地、摆放、价值与修复成本。
- `lib/pawn/customers.ts`：带种子的客流、需求与条件剧情。
- `lib/pawn/discovery.ts`：实际见货记录与早期 v3 存档的发现记录恢复。
- `lib/pawn/engine.ts`：交易、契约、加工、风险与贷款规则。
- `lib/pawn/save.ts`：新版存档校验与独立存储键。
- `components/pawn/`：柜台、仓储、经营管理与存档界面。
- `components/pawn/LegacyGame.tsx` 与 `lib/game.ts` 等旧模块：保留可继续游玩的七日篇。
- `app/pawnshop.css`：新版界面样式；原美术素材继续使用。

## 开发和验证

使用 Node 24 与 npm，保留现有 lockfile。

```sh
npm install
npm run dev
npm test
npx tsc --noEmit
npm run build:pages
npm run build
```

测试包括旧版回归、新版规则边界与三条经营路线的多随机种子整局模拟；模拟过程中持续验证保存与恢复。不使用隐藏买家底价作策略决策，接受柜台显示的还价。
